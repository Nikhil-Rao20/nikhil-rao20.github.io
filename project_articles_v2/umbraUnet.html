Umbra UNet: A Hybrid Framework for Robust Segmentation of Underrepresented Classes in Satellite Imagery

Abstract

Semantic segmentation of satellite imagery presents a particularly difficult class imbalance problem: dominant land-cover classes such as roads and vegetation occupy the vast majority of pixels, while critical minority classes — airstrips, harbors, ground tracks — occupy only a fraction. Standard segmentation losses and architectures are systematically biased toward majority classes, producing poor minority-class detection. This paper presents Umbra UNet, a hybrid architecture combining three parallel encoding branches (InceptionNeXt, EfficientViT, ConvNeXtV2) with a joint Combo Loss (Focal + Dice + Tversky). On the DLRSD 17-class satellite dataset, Umbra UNet achieves an overall Dice of 0.856 versus the UNet baseline of 0.847, with Minority Class Recall improving from 0.623 → 0.701 — a substantially more meaningful gain than the headline Dice suggests.

Introduction

Remote sensing data from satellites and aerial platforms provides critical intelligence for urban planning, disaster response, agricultural monitoring, and defense reconnaissance. The DLRSD (DOTA-style Large Remote Sensing Dataset) presents 17 semantic classes with a pronounced imbalance: major categories collectively constitute over 80% of labeled pixels, while critical infrastructure classes — airstrips, storage tanks, ground tracks — may represent less than 1%.

In this context, mainstream segmentation models severely underperform on minority classes. Standard cross-entropy loss and Dice loss both converge to solutions that sacrifice minority-class accuracy in exchange for overall metric improvement. For applications where minority class detection is operationally critical, this represents a fundamental failure mode.

This work addresses the problem from three complementary directions simultaneously: architecture (multi-branch parallel encoding for richer representations), loss function (Combo Loss targeting multiple failure modes), and optimization (AdamW with weight decay for regularized convergence). The resulting Umbra UNet framework demonstrates that systematic, multi-pronged mitigation is necessary — no single intervention suffices.

Methodology

Umbra UNet's design is structured around three simultaneous interventions. Each addresses a distinct failure mode of standard segmentation pipelines applied to imbalanced satellite data.

1. Hybrid Parallel Encoder Architecture

Rather than a single-branch encoder, Umbra UNet uses three parallel encoding paths that independently extract features at each scale before fusion:

InceptionNeXt Branch

Inspired by Inception modules and modernized with depthwise convolutions, InceptionNeXt excels at capturing multi-frequency spatial patterns. It provides strong local texture representations — critical for identifying fine-grained minority classes like ground tracks and storage tanks.

EfficientViT Branch

A memory-efficient vision transformer providing global context via multi-scale attention. This branch captures long-range dependencies between spatially separated instances of the same class — important for geographically scattered minority objects.

ConvNeXtV2 Branch

A modernized pure-CNN architecture with FCMAE pretraining and Global Response Normalization. Provides robust hierarchical feature maps with strong ImageNet-scale transfer. Serves as the backbone for majority class regions while complementing the attention branch.

Features from all three branches are fused at each decoder stage via addition followed by a convolutional projection, preserving multi-branch diversity while remaining parameter-efficient.

Fig. 2 — Conceptual diagram of multi-stream feature fusion within the hybrid encoder.

2. Combo Loss

A weighted combination of three complementary loss functions, each targeting a different aspect of the imbalance problem:

Focal Loss

Downweights easy majority-class examples, focusing gradient updates on difficult minority class pixels. The modulating factor γ = 2 provides the standard calibration for strongly imbalanced datasets.

Dice Loss

Directly optimizes the segmentation overlap metric. Scale-invariant and effective at preventing the model from collapsing to majority-class predictions. Used as the primary structural loss.

Tversky Loss

A generalization of Dice loss with asymmetric weighting of false positives (α) and false negatives (β). Setting β > α places higher penalty on missed minority class detections — directly improving recall for small, underrepresented classes.

3. AdamW Optimization

AdamW's decoupled weight decay provides stronger regularization than standard Adam without degrading convergence. For multi-branch architectures, this prevents co-adaptation of branches and improves generalization to rare class patterns. Cosine annealing learning rate scheduling with warm restarts prevents premature convergence on easy majority samples.

Key Result

While the overall Dice improvement from 0.847 → 0.856 appears modest, the Minority Class Recall gain (0.623 → 0.701, a 12.5% relative improvement) represents the primary operational success of this work. For remote sensing applications where missing a minority class object carries high cost, this distinction is critical and not captured by headline Dice alone.

Discussion

The results validate the three-pronged hypothesis. Single-intervention baselines (UNet + Focal Loss, ConvNeXtV2 alone) improve minority class recall modestly; combining all three interventions achieves the largest gain. This confirms that architecture, loss function, and optimizer must all be aligned in service of the minority-class objective.

The parameter cost of the parallel branch design (74.1M vs. 31.0M for standard UNet) is a real trade-off. For deployments with strict inference latency constraints, a distillation of the Umbra UNet backbone into a lighter single-branch model is a recommended next step.

This hackathon context also provides an important caveat: the DLRSD benchmark, while representative, covers a limited range of geographic regions and sensor modalities. Validation on diverse operational datasets — including SAR, multispectral, and very-high-resolution commercial imagery — remains necessary before deployment in operational systems.

Conclusion

Umbra UNet demonstrates that robust minority class segmentation in satellite imagery requires a coordinated multi-pronged approach. The parallel InceptionNeXt/EfficientViT/ConvNeXtV2 encoder, Combo Loss, and AdamW optimization together produce a 12.5% relative minority recall improvement over the baseline. This framework is generalizable beyond satellite imagery to any high-stakes segmentation task where critical classes are statistically underrepresented — including medical imaging, industrial inspection, and autonomous navigation.
